# Sera--Smart-Search-Assistant  
> About The Project  
**Description**  
Sera(Smart Search Assistant) is an intelligent agentic web navigation system designed to autonomously perform human-like web browsing behaviors based on natural language goals. It can search, read, click, scroll, and complete structured tasks across arbitrary websites with changing layouts and DOM structures. Leveraging modular design principles, Sera combines advanced Large Language Models (LLMs) for task planning with DOM-aware execution modules and browser automation to provide a transparent, interpretable, and deployable solution for automating complex web tasks.
Users can input queries via text or voice, enabling a hands-free, conversational interface to issue web search queries or task instructions naturally. The system processes voice inputs, converts them to text, and seamlessly integrates the commands into the planning and execution pipeline.  
**Deliverables**
1. Develop an AI Agent to convert natural language or voice-transcribed queries into structured multi-step plans using prompt engineering or fine-tuning.
2. Build another AI Agent to translate each plan step into precise DOM-aware browser actions using fine-tuned LLMs.
3. Integrate Playwright to fetch DOM snapshots, execute browser actions (click, type, scroll), and enable closed-loop navigation.
4. Design a simple UI for users to input queries (via text or voice), track agent progress, and view final outputs.
5. Implement voice activation with the wake phrase “Hey Sera” using open-source speech-to-text systems.
